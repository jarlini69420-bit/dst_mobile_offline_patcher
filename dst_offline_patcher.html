DST Cluster Offline Patcher

Runs entirely in your browser — nothing is uploaded anywhere. Open a zipped cluster folder, patch it to offline, and download the result.

FILES IN ARCHIVE (tap to view/edit, or open a nested zip)

MODS TO CONFIGURE (optional — used by Patch → Offline)

If this box has any mod names when you click Patch → Offline, every shardindex found gets its enabled_mods replaced with exactly this list (all set enabled=true). Leave it empty to patch offline without touching mods at all.

PATCH DIRECTION

Offline: sets offline_cluster=true / lan_only_cluster=true in every cluster.ini, and online_mode=false in every shardindex — recursively, including nested zips like Master.zip/Caves.zip.
Online: sets the same flags back to false / true respectively, AND clears each shardindex's enabled_mods list — the mods it removes are listed below so you can re-add them next time you go offline.
cluster_token.txt is left alone either way. Your original zip is untouched — this builds a new one.

MODS CLEARED (from Patch → Online)

Keep this somewhere — next time you patch this world back to offline, re-add these mod names to enabled_mods by hand.
